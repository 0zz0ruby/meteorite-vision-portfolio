# 陨石视觉项目个人工作说明

## 1. 文档目的与结论

本文件用于说明作者在陨石视觉项目中实际完成的工作、采用的技术路线、主要实验结果、失败实验及个人与团队贡献边界。内容综合以下材料整理：

- 分类项目过程重建记录
- 第一阶段 ResNet-18 训练 Notebook、数据集代码及中期报告
- 第二阶段 DINOv2 训练代码、最终 checkpoint、模型权重和后期报告
- 外部陨石图集备份及背景移除相关材料
- 六个生成模型调参 Notebook、FID 结果和个人实验报告

整个工作可以分为两条相关但任务目标不同的主线：

1. **陨石图像分类与跨域泛化**：团队 Kaggle 课程项目，目标是区分陨石与非陨石。个人主要负责 ResNet-18 基线、DINOv2 训练与消融、外部数据采集，以及提出多模型投票集成思路。
2. **陨石图像生成**：后续个人作业，复用前景提取后的陨石样本，独立构建并迭代 DCGAN/WGAN-GP 生成模型，以 FID 评价生成质量。

项目最能体现的能力不是简单调用多个模型，而是：发现本地验证和线上测试之间的域偏移，设计对照实验定位原因，判断无效方案并及时回退，最后利用不同模型的互补性提出集成方案。

## 2. 项目一：陨石图像分类与跨域泛化

### 2.1 任务背景

任务目标是对图片进行二分类，判断图片中的物体是否为陨石。训练数据约 5,098 张，其中：

- 陨石类（类别 1）：2,685 张；
- 非陨石类（类别 0）：2,413 张。

项目的核心困难是训练集与测试集之间存在明显的域偏移。训练图片中包含尺子、色块、桌面背景和固定拍摄条件，而测试图片在光照、背景、清晰度、拍摄角度和目标大小上变化较大。模型容易记住背景、标尺或色块等伪特征，而不是学习陨石的熔壳、表面纹理、轮廓和风化特征。

因此，项目目标逐步从“提高本地验证分数”转向“建立可信验证方案并提高未知测试数据上的泛化能力”。

### 2.2 个人贡献总览

| 工作模块 | 个人贡献 | 主要结果 |
|---|---|---|
| ResNet-18 基线 | 独立搭建数据读取、训练、验证、阈值搜索和提交生成流程 | 本地验证 F1 0.9852，第一阶段线上 F1 0.72222 |
| 伪相关实验 | 在负类图片中注入黑色比例尺块，检验模型是否依赖背景捷径 | 发现本地验证和线上表现存在明显差距 |
| DINOv2 | 负责模型设计、训练配置、增强、TTA和消融 | 单模型第二阶段线上 F1 0.73 |
| 验证集改进 | 使用图片哈希进行相似图片分组，降低近重复数据泄漏 | 提高验证评估的可信度 |
| 外部数据扩充 | 爬取陨石图片、去重、背景移除并开展扩充实验 | 新增数据后 F1 从 0.73 降至 0.71，定位额外域偏移 |
| 多模型集成 | 发现单模型优化收益有限后提出投票思路，与团队共同实现 | 四模型集成最终 F1 0.78284 |

## 3. 第一阶段：ResNet-18 基线

### 3.1 数据读取与工程流程

个人完成了一个完整的 PyTorch 图像分类流程：

- 从 `train_labels.csv` 中读取图片 ID 和标签；
- 自动识别 `.jpg`、`.jpeg`、`.png` 等图片扩展名；
- 分别为训练、验证和测试阶段配置数据变换；
- 使用 `Dataset`、`Subset` 和 `DataLoader` 组织数据；
- 固定 Python、NumPy 和 PyTorch 随机种子；
- 检查训练集和验证集索引是否重叠；
- 保存验证 F1 最优的模型权重；
- 预测测试集并生成 Kaggle 格式的 `submission.csv`；
- 绘制训练/验证 Loss、F1 曲线和混淆矩阵。

### 3.2 验证集设计

从全部 5,098 张带标签图片中划分：

- 训练集：4,598 张；
- 验证集：500 张；
- 验证集类别分布：400 张非陨石、100 张陨石。

该 4:1 类别比例用于模拟第一阶段测试集的类别倾斜。代码检查结果显示训练集和验证集交集为 0。

这种设计比完全随机划分更接近当时对测试分布的判断，但后续线上结果仍证明：仅调整类别比例不能消除背景、拍摄条件和近重复图片造成的分布差异。

### 3.3 数据预处理与增强

训练阶段使用：

- Resize 至 `224×224`；
- 随机水平翻转，概率 0.5；
- 随机旋转 ±15°；
- 亮度、对比度和饱和度 ±0.15，色调 ±0.05 的 ColorJitter；
- ImageNet 均值和标准差归一化。

验证和测试阶段只进行确定性的尺寸调整与归一化，不使用随机增强。

### 3.4 黑色比例尺块伪相关实验

训练代码中实现了 `add_fake_scale_block`：只对类别 0 的训练图片以约 25% 概率添加深色矩形，并随机放置在图像边缘，模拟真实数据中的比例尺或色块。

该实验的目的不是把黑块当作最终增强，而是主动制造“黑块—非陨石”的虚假关联，检验模型会不会依赖容易学习的统计捷径。验证集和测试集不添加黑块，从而观察模型面对伪相关失效时的泛化能力。

这一设计对应机器学习中的 **shortcut learning / spurious correlation** 问题。

### 3.5 模型与训练配置

- Backbone：ImageNet 预训练 ResNet-18；
- 分类头：将最后全连接层替换为 2 类输出；
- 微调方式：不冻结 Backbone，全参数微调；
- Epochs：15；
- Batch size：32；
- Optimizer：Adam；
- Learning rate：`1e-4`；
- Weight decay：`1e-4`；
- Scheduler：StepLR，每 5 轮乘以 0.5；
- Loss：带类别反比权重的 CrossEntropyLoss；
- 模型选择指标：验证集 F1。

### 3.6 实验结果与判断

最佳模型出现在第 3 个 Epoch：

- 验证 Loss：约 0.0188（报告中另一版本记录为 0.0264）；
- 陨石类验证 F1：0.9852；
- 验证集 Macro-F1：约 0.9907；
- 混淆矩阵：400 张非陨石中误判 3 张，100 张陨石全部识别正确；
- 第一阶段 Kaggle F1：0.72222。

训练后期训练 F1 接近 1，但验证 F1 在最佳轮次后明显波动，说明模型存在过拟合。本地验证约 0.99 与线上约 0.72 的差距表明，验证集仍无法代表真实测试分布。

### 3.7 分类阈值搜索

个人在验证集上保存陨石类别概率，并搜索 0.10–0.90 的分类阈值。结果显示：

- 默认阈值 0.5 时验证 F1 为 0.9852；
- 阈值约 0.63–0.71 时验证 F1 可达到约 0.9901。

这说明 F1 会受到 Precision/Recall 平衡和分类阈值影响。不过，由于验证集本身存在域偏移，阈值优化不能替代可信的验证划分。

### 3.8 第一阶段得到的认识

1. 本地验证分数很高不等于测试集泛化能力强。
2. 模型可能学习背景、标尺和色块，而不是陨石本体。
3. 继续提高训练集准确率意义有限，应优先解决验证偏差、域偏移和过拟合。
4. 需要尝试更通用的视觉表征、背景鲁棒增强和多模型互补。

## 4. 第二阶段：DINOv2 训练、优化与消融

### 4.1 选择 DINOv2 的原因

第二阶段测试图片的拍摄环境变化更大。个人选择 DINOv2，是因为其在大规模无标签图像上进行自监督预训练，能够提供相对通用的纹理、形状和语义表征，适合小样本与域偏移场景。

相比直接训练更大的 CNN，冻结 DINOv2 Backbone 可以降低可训练参数量和过拟合风险。

### 4.2 模型结构

最终方案采用：

- Backbone：DINOv2 ViT-S/14；
- 冻结 Backbone，仅训练线性分类头；
- 提取最后两个 Transformer Block 的 CLS Token；
- 每层 CLS Token 为 384 维；
- 拼接后形成 768 维特征；
- 使用线性层输出两个类别。

代码重写了模型的 `train()` 行为，使冻结的 Backbone 始终保持评估模式，避免预训练特征在训练分类头时发生不必要的状态变化。

### 4.3 数据划分与防泄漏

个人在 DINOv2 流程中引入图片哈希分组：

- 对图片计算感知哈希；
- 将相同或近似图片归为同组；
- 使用分组划分保证相似图片不会同时进入训练集和验证集；
- 降低近重复图片造成的验证数据泄漏。

这一步针对的是普通随机划分中“看似验证分数很高，实际只是见过近似图片”的风险。

### 4.4 最终训练配置

最终 DINOv2 checkpoint 中保存的参数为：

| 参数 | 数值 |
|---|---:|
| Model | DINOv2 ViT-S/14 |
| Image size | 224 |
| CLS layers | 最后 2 层 |
| Feature dimension | 768 |
| Batch size | 128 |
| Learning rate | 0.003 |
| Weight decay | 0.01 |
| Epochs | 30 |
| Early stopping patience | 8 |
| Validation size | 20% |
| Seed | 42 |
| Train image folder | `train_images_bg_removed` |
| Monitor | Validation Macro-F1 |

最终权重记录的最佳验证 Macro-F1 约为 0.9204，出现在第 28 轮。课程报告记录的另一轮最佳验证 Macro-F1 为 0.913，说明报告和最终 checkpoint 可能来自不同运行。

### 4.5 数据增强与 TTA

训练阶段保留：

- RandomResizedCrop；
- 水平翻转；
- 垂直翻转；
- GaussianBlur；
- ImageNet 标准化。

没有继续使用过强的 ColorJitter 和 RandomErasing，以避免破坏陨石表面细粒度纹理。

测试阶段启用四路 TTA：

1. 原图；
2. 水平翻转；
3. 垂直翻转；
4. 水平与垂直双向翻转。

四路预测概率取平均后生成最终类别。

### 4.6 DINOv2 消融结果

| 实验 | 线上 F1 | 结论 |
|---|---:|---|
| ViT-S/14 + 双层 CLS + GaussianBlur + TTA | **0.73** | 最佳 DINOv2 方案 |
| 单层 CLS Token（384 维） | 0.70 | 双层特征包含有效互补信息 |
| ViT-B/14 | 0.68 | 模型规模过大，在小数据集上过拟合 |
| 外部陨石图片扩充 | 0.71 | 新数据带来额外域偏移 |
| 移除 GaussianBlur | 0.70 | GaussianBlur 对泛化有正向作用 |
| 分阶段分辨率训练 | 无显著提升 | 更复杂的训练流程没有稳定收益 |

这些消融说明个人工作不仅是运行预训练模型，还包括围绕特征层、模型容量、增强策略和数据来源设计对照实验。

## 5. 外部陨石数据采集、去重与背景处理

### 5.1 数据采集目标

为缓解训练集陨石样本不足，个人从 Meteoritical Bulletin 等来源采集外部图片。采集规划并不局限于白底标准样本，而是考虑：

- 熔壳、风化和切面特征；
- 野外、桌面和手机拍摄；
- 不同亮度、清晰度和目标大小；
- 玄武岩、矿渣和铁矿石等 hard negatives。

### 5.2 数据处理链路

过程记录显示，数据链路覆盖：

- 网页图片 URL 提取；
- 详情页和缩略图下载；
- 自动爬取陨石资料；
- 文件有效性检查；
- 使用 pHash 与原训练集去重；
- 使用 `rembg` 批量移除背景；
- 支持跳过已生成结果和断点续跑；
- 保留原始图片与去背景版本。

现存压缩包中可确认约 105 张外部原图及约 105 张去背景版本。报告写“约 120 张”，可能对应另一个阶段的数据版本。申请材料中写“100+ 张”最严谨。

### 5.3 数据扩充实验结果

外部数据加入训练集后，DINOv2 线上 F1 从 0.73 降至 0.71。个人据此分析：

- 网站图片与竞赛图片的拍摄风格不同；
- 高分辨率图片和原训练集纹理分布不一致；
- `rembg` 会改变主体边缘和背景统计；
- 新样本数量约只占原数据 3%，不足以弥补新引入的域偏移；
- 与继续增加正类相比，补充 hard negatives 可能更有效。

这一实验表明：更多数据并不必然提升模型，数据来源和目标域匹配程度更加关键。

## 6. 多模型投票集成思路

### 6.1 提出集成的原因

团队分别探索 ConvNeXt、EfficientNetV2-S、DINOv2 和 Swin Transformer，但单模型线上结果主要集中在约 0.67–0.74，继续对单一模型调参的收益逐渐降低。

个人据此提出多模型投票思路，希望利用不同网络架构之间的错误互补性提高预测稳定性。最终阈值、权重和实现由团队共同完成。

### 6.2 四个模型的互补角色

- ConvNeXt：局部纹理和形状判别；
- EfficientNetV2-S：高效 CNN 局部特征；
- DINOv2：自监督预训练视觉表征；
- Swin Transformer：窗口注意力和多尺度结构补充。

### 6.3 三值置信投票

最终方法没有直接平均概率，而是为每个模型设置低、高置信阈值：

- 概率高于高阈值：高置信支持陨石，记为 `+1`；
- 概率低于低阈值：高置信支持非陨石，记为 `-1`；
- 概率位于中间区间：模型弃权，记为 `0`。

之后对四个模型的投票进行加权，并通过最终总分阈值得到分类结果。中间概率不直接参与决策，可以降低边界样本和偶然误判的影响。

现存截图保留了一组可核验的 v2 参数：

| 模型 | 低阈值 | 高阈值 | 投票权重 |
|---|---:|---:|---:|
| ConvNeXt-Tiny | 0.4891 | 0.6124 | 0.2696 |
| Swin V2-S | 0.5862 | 0.6973 | 0.0981 |
| DINOv2 ViT-S/14 | 0.2460 | 0.8884 | 0.2489 |
| EfficientNetV2-S | 0.0905 | 0.4400 | 0.3834 |

四项权重之和为 1.0，总分判决阈值为 `-0.1750`。该组参数对应截图中的
`submission_confidence_interval_threshold_v2.csv`，公开 F1 为 **0.78260**。

需要区分的是，课程最终排行榜记录的团队成绩为 **0.78284**，但最终拟合脚本及对应参数没有保留。
因此，上表应准确描述为“现存 v2 配置”，不能声称它一定就是 0.78284 对应的最终参数。

### 6.4 最终结果

- 已留存 v2 配置公开 F1：**0.78260**；
- 课程排行榜中的团队最终 F1：**0.78284**；
- 第二阶段测试样本：194 张；
- 预测类别 0：96 张；
- 预测类别 1：98 张。

准确的个人贡献表述为：

> 观察到单模型优化收益逐渐减弱后，提出多模型投票集成思路，并与团队共同实现四模型置信阈值加权投票。

## 7. 团队模型与解释分析

以下工作构成完整团队项目背景，但不能全部表述为个人独立完成：

### 7.1 ConvNeXt-Tiny

- ImageNet-1K 预训练；
- 全参数微调；
- 强通用增强、标签平滑、混合精度和早停；
- 最佳线上 F1 约 0.74；
- 白底预处理、伪标签、中间域预训练和测试相似度划分均未超过基线。

### 7.2 EfficientNetV2-S

- 基线线上 F1 约 0.72；
- 多阶段冻结/解冻后下降至约 0.60；
- 本地验证 F1 可达 0.96+，进一步说明验证集偏乐观。

### 7.3 Swin Transformer

- Swin V2-S，输入 384×384；
- 尝试 EMA、Focal Loss、SAM、SWA、ArcFace、MixUp/CutMix、背景移除等 16 种变体；
- EMA 是唯一明确有效的单点改进；
- 本地 Macro-F1 约 0.998，线上 F1 仅 0.6743；
- MixUp/CutMix、背景移除和直方图匹配均造成明显下降。

### 7.4 Grad-CAM 与错误分析

团队使用 Grad-CAM 发现：

- 正确预测时，注意力集中在陨石轮廓、熔壳和表面纹理；
- 错误预测时，注意力可能落在标尺、色块和桌面背景；
- 直接背景移除可能破坏 CNN 依赖的主体边缘；
- 背景移除对 DINOv2 和 CNN 模型的影响并不一致。

如果没有更明确的成员分工证据，该部分适合写作“参与团队分析”或“团队通过 Grad-CAM 发现”。

## 8. 项目二：陨石图像生成

### 8.1 与分类项目的关系

该任务是后续个人作业，不是 Kaggle 分类竞赛的同一个评价任务。它复用了前景提取并放置在白色背景上的陨石样本，可以作为同一陨石视觉主题下的生成建模扩展。

任务要求使用 2,682 张陨石图片学习图像分布，生成 1,000 张新图片，并使用官方 InceptionV3 FID 脚本评价。FID 越低，生成分布越接近真实图片。

### 8.2 工程与评估流程

个人完成：

- 加载和预处理 2,682 张陨石图片；
- Resize、随机水平翻转和 `[-1,1]` 归一化；
- GPU、CUDA和显存检测；
- 根据显存自动选择 batch size；
- 定期保存 checkpoint 与固定噪声九宫格；
- 从随机噪声批量生成 1,000 张图片；
- 清理旧生成图片，避免 FID 数量混乱；
- 调用官方 `evaluate_fid.py`；
- 保存 `fid_metrics.json`；
- 手工选择 9 张生成效果较好的图片并编写 LaTeX 报告。

### 8.3 v0：DCGAN 基线

配置：

- 分辨率：64×64；
- 隐变量：100维；
- 基础特征图：64；
- Batch size：128；
- Epochs：300；
- Loss：BCE；
- Optimizer：Adam；
- Generator：转置卷积 + BatchNorm + ReLU；
- Discriminator：卷积网络 + Sigmoid。

结果：

- 完整训练 300 轮；
- 生成 1,000 张图片；
- FID：**245.9168**；
- 白像素占比约 77.6%。

通过九宫格和白像素比例发现，生成器输出大量接近空白的图片，说明 BCE GAN 训练不稳定，模型倾向于复制容易生成的白色背景。

### 8.4 v1：WGAN-GP

核心改动：

- BCE 改为 Wasserstein Loss；
- Discriminator 改为无 Sigmoid 的 Critic；
- 增加 Gradient Penalty；
- 分辨率提高至 128×128；
- 隐变量提高至 128维；
- 每更新一次 Generator，更新三次 Critic；
- Adam 参数调整为 `β1=0, β2=0.9`。

结果：

- 完整训练 300 轮；
- 生成 1,000 张图片；
- FID：**189.7166**；
- 白像素占比降至约 63.6%。

从 DCGAN 切换至 WGAN-GP 带来约 56 点的 FID 改善，是最大的一次结构性提升。

### 8.5 v2：平衡 Generator 与 Critic

核心改动：

- `FEATURE_MAPS`：64→96；
- `N_CRITIC`：3→2；
- Generator 学习率：`1e-4`→`1.5e-4`；
- Critic 学习率：`1e-4`→`5e-5`；
- 训练上限：300→500轮。

设计逻辑是增加 Generator 的容量与相对更新速度，同时降低 Critic 的学习速度，避免 Critic 过强导致 Generator 只能输出安全的白色背景。

报告记录 FID 为 **170.82**。Notebook 保存的输出运行至约第 468 轮，最后部分输出未完整保留。

### 8.6 v3：SpectralNorm 与更大隐空间

核心改动：

- Critic 中的 InstanceNorm 改为 SpectralNorm；
- 删除中间归一化层；
- 隐变量维度：128→256；
- Gradient Penalty 系数：10→5；
- Generator 学习率提高至 `2e-4`；
- Critic 学习率保持 `5e-5`；
- 训练上限提高到600轮。

设计理由：InstanceNorm 会让同一批样本之间发生统计耦合，可能削弱 WGAN-GP 对单样本梯度的约束。SpectralNorm直接约束层的谱范数，更适合稳定 Critic。

结果：

- 报告表格中的一次评估：FID 137.25；
- 最终官方 `fid_metrics.json`：FID **134.2034**；
- 真实图片数量：2,682；
- 生成图片数量：1,000。

最终申请材料应使用官方最终结果 **FID 134.20**，并将 137.25 理解为同一版本的较早检查点评估。

### 8.7 v4：EMA与强增强失败实验

尝试内容：

- EMA，衰减率 0.999；
- `FEATURE_MAPS`：96→128；
- ±10°随机旋转；
- ColorJitter。

结果：FID 恶化至 400 以上，因此放弃该方案并回退到 v3。

可能原因：

- EMA衰减率过高，生成器权重更新滞后；
- 模型容量增加后，小数据训练更不稳定；
- 旋转和颜色增强改变了白底实验室陨石图片的真实分布；
- 多项改动同时加入，难以隔离单个因素。

### 8.8 Feature Matching 探索

目录中存在 Feature Matching 版本 Notebook，说明个人进一步探索过特征匹配损失。但现存输出不足以证明该版本完整训练并得到可信 FID，因此只能描述为“编写并尝试 Feature Matching 方案”，不能作为最终实验成果。

### 8.9 生成项目结论

1. WGAN-GP比标准DCGAN显著稳定。
2. SpectralNorm是后期最有效的结构改动。
3. 增加生成器容量和隐变量维度有帮助，但继续盲目增大模型会产生负作用。
4. 调整Generator/Critic学习率和更新频率比单纯增加Epoch更有效。
5. EMA和数据增强并非必然有效，需要与数据分布和训练阶段匹配。
6. 最终FID仍较高，生成图像存在白色背景过多、主体偏小和纹理细节不足的问题。

在陨石图像分类项目中，我首先负责构建ResNet-18迁移学习基线，并通过验证集重构、黑色色块伪相关实验和分类阈值搜索，发现本地验证F1接近0.99但线上仅约0.72，说明模型受到背景捷径和训练—测试域偏移影响。第二阶段我负责DINOv2路线，冻结ViT-S/14骨干网络并拼接最后两层CLS Token，通过图片哈希分组、背景移除、GaussianBlur和四路TTA提升泛化，单模型线上F1达到0.73。我还爬取并处理100余张外部陨石图片，通过消融发现不匹配的外部数据反而引入新的域偏移。观察到不同单模型继续优化的收益有限后，我提出多模型投票思路，并与团队共同实现四模型置信阈值加权投票，最终F1达到0.78284。随后在个人生成模型作业中，我进一步使用同主题陨石样本，从DCGAN迭代到WGAN-GP与SpectralNorm，将官方FID从245.92降低至134.20。
